## 试一遍

1. 启动离线模式，注册自己的 EDZ 目录，等待索引完成。
2. 搜索一个自己知道的型号，双击打开部件预览。
3. 收藏到个人部件库，再次打开核对来源。
4. 需要导出时，先核对 EPLAN 版本与来源，在工程副本上按向导预览。
